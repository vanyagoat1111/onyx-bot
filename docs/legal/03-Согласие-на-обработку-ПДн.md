[ ⬅️ Назад ]

Что фиксируется при нажатии «Принимаю»:

| Поле | Значение |
|---|---|
| telegram_id | ID пользователя |
| consent_type | `pdn` |
| consent_version | версия документа, например `1.0` |
| accepted | `true` |
| date / time | дата и время по московскому времени |
| source | `bot` |
| doc_url | ссылка на текст документа этой версии |
