# Регламент хранения и уничтожения персональных данных

**Внутренний документ операторов ONYX WEB**
**Версия:** 1.0 · **Утверждён:** \_\_\_\_\_\_\_\_\_\_\_\_

> Этот документ Роскомнадзор запрашивает при проверке. Он должен не просто существовать, а реально исполняться — фиксируйте акты уничтожения.

---

## 1. Назначение

Регламент определяет сроки хранения персональных данных, порядок их уничтожения и обезличивания, а также порядок реагирования на обращения субъектов об удалении данных.

## 3. Порядок уничтожения

3.1. **Периодичность проверки.** Ответственный за организацию обработки ПДн не реже **одного раза в полгода** проверяет наличие данных с истёкшим сроком хранения.

3.2. **Способы уничтожения:**
- в электронной базе — удаление записи без возможности восстановления, включая удаление из резервных копий при их плановой ротации;
- в таблицах — удаление строки;
- материалы в облачном хранилище — удаление файлов и очистка корзины;
- бумажные носители (при наличии) — измельчение.

3.3. **Обезличивание** применяется, если сведения нужны для статистики: удаляются имя, телефон, e-mail, Telegram ID, ИНН, наименование организации; остаются агрегированные показатели (ниша, город, сумма, тариф).

3.4. **Акт уничтожения.** По результатам составляется акт с указанием: даты, категорий данных, количества записей, способа уничтожения, ФИО ответственного. Акты хранятся 3 года.

Форма акта — Приложение 1.

## 4. Удаление по обращению субъекта

4.1. Обращение принимается по адресу **onyxwebcooperation@gmail.com** либо через раздел «📄 Документы» → «Мои данные» в боте.

4.2. Порядок обработки обращения:

| Шаг | Действие | Срок |
|---|---|---|
| 1 | Регистрация обращения | в день поступления |
| 2 | Идентификация заявителя | 1 рабочий день |
| 3 | Проверка наличия оснований для дальнейшего хранения | 3 рабочих дня |
| 4 | Удаление либо мотивированный отказ | до 10 рабочих дней с даты обращения |
| 5 | Уведомление заявителя о результате | одновременно с п. 4 |

4.3. **Основания для отказа в удалении** (данные сохраняются, заявителю направляется мотивированный ответ):
- данные необходимы для исполнения действующего договора;
- не истёк срок хранения документов по расчётам (4 года);
- имеется неурегулированный спор либо судебное разбирательство.

В этом случае обработка ограничивается хранением; данные исключаются из рассылок и не используются для иных целей.

4.4. **Отзыв согласия** обрабатывается в тот же срок. При отзыве согласия на рекламные сообщения отписка производится **не позднее следующего рабочего дня**.

## 5. Резервные копии

5.1. Резервные копии хранятся не более **90 дней**, после чего перезаписываются.

5.2. При удалении данных по обращению субъекта запись удаляется из основной базы немедленно; из резервных копий — при плановой ротации, но не позднее 90 дней. Заявитель уведомляется об этом.

## 6. Ответственность

Контроль исполнения Регламента возлагается на ответственного за организацию обработки персональных данных. Нарушение сроков хранения является нарушением ч. 4 ст. 5 152-ФЗ.
